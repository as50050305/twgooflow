# twgoo — 台股盤後法人資金流向儀表板

自己用的台股儀表板：盤後三大法人、融資融券、板塊資金流向、短線動能選股與回測，盤中即時報價與大筆資金突破訊號。

- `fetch.py`：盤後資料（證交所、櫃買中心、公開資訊觀測站、集保），輸出 `data/` 給儀表板讀
- `live.py`：盤中服務（http://localhost:8765）
- `dashboard.html`：儀表板，直接用瀏覽器開
- `run.bat`／`live.bat`／`setup_task.bat`：手動執行與建立 Windows 排程

只用 Python 標準函式庫（3.7 以上）。`data/`、`logs/` 不放進版本控制，第一次執行 `run.bat` 會自動抓。
