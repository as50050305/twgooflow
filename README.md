# twgoo — 台股盤後法人資金流向儀表板

自己用的台股儀表板：盤後三大法人、融資融券、板塊資金流向、短線動能選股與回測，大盤（加權、櫃買）與台指期 K 線、期貨法人未平倉，盤中即時報價與大筆資金突破訊號。

只用 Python 標準函式庫（3.7 以上），不需要另外安裝套件。`data/`、`logs/` 不放進版本控制，第一次執行 `run.bat` 會自動抓。

> 資料來源：臺灣證券交易所、證券櫃檯買賣中心、臺灣期貨交易所、公開資訊觀測站、臺灣集中保管結算所公開資料。本工具僅供個人參考，不構成投資建議。

## 第一次使用

1. **雙擊 `run.bat`**：第一次會回補 60 個交易日（約 40 分鐘）。中途關掉沒關係，再執行會接著抓。
2. **雙擊 `setup_task.bat`**：建立自動排程。
   - 每個交易日 18:45 與 21:45 抓盤後資料（21:45 那次補抓比較晚公布的融資資料；電腦當時沒開的話，開機後會補跑）。
   - 每個交易日 08:40 啟動「盤中服務」：會開一個黑色視窗，開著才會更新，收盤後約 14:10 自動結束。
3. **雙擊 `dashboard.html`** 用瀏覽器開啟（建議 Chrome 或 Edge）。
4. **盤中要看即時**：只要盤中服務在跑（08:40 排程或雙擊 `live.bat`），直接開 `dashboard.html` 也會自動連上；也可以開 http://localhost:8765 。瀏覽器若問「要允許存取本機網路上的裝置嗎」，請按允許。

## 常用指令

在這個資料夾按住 Shift＋右鍵 →「在終端機中開啟」：

```bat
py fetch.py --show 2330,2317              :: 顯示最新一天的原始數字，方便跟證交所網站對照
py fetch.py --show 2330 --date 20261007   :: 指定日期
py fetch.py --check                       :: 每天「個股估算加總 vs 官方金額」的誤差
py fetch.py --rebuild                     :: 改完 sectors.csv 後只重算、不重抓
```

沒有 `py` 指令的話，把 `py` 換成 `python`。

## 短線動能選股（「動能」分頁）

- 第一次打開會載入歷史資料（約 10 MB），桌機約 1～3 秒。
- 分頁：選股清單（6 個內建策略＋自訂策略，第 6 個是收盤後的「大筆資金突破」）、族群動能、回測、設定、公式說明。
- 動能分數有兩種，在「動能 → 設定」切換（預設乖離動能）：
  - **乖離動能**＝收盤（還原權息）÷ 12 日指數平均 − 1，以 % 表示，預設門檻 7.5；可以是負數，也可以超過 10。
  - **排名動能**＝報酬與乖離在全市場的百分位加權，0～10 分，預設門檻 8。兩種的門檻各自記住。
- 所有權重、門檻、燈號參數、策略條件、停損方式、回測成本都在「動能 → 設定」修改，存在瀏覽器裡。
- 自選股可以「記錄進場」（日期、價格、停損），通知欄會提醒跌破停損、動能轉弱與新進入策略的股票。
- 歷史長度由 `config.json` 的 `history_trading_days` 控制（預設 490 個交易日，約 2 年；動能與回測用最近約 1 年）。
- 回測可選「全市場」或「單一股票」：單一股票會顯示每筆交易、K 線上的買賣點、策略 vs 一直抱著不動，也可以按「比較全部策略」看每個策略在這檔的表現。區間約 1 年，一檔通常只有幾筆交易，結果只能參考。

## 個股頁：K 線、基本面、籌碼

- **K 線**：最多約 2 年，可切換日／週／月 K、5／20／60 日線、法人買賣超柱、動能線；滑鼠滾輪或雙擊縮放、拖曳移動，手機兩指縮放。
- **估值**：本益比（附近 1 年百分位）、殖利率、股價淨值比、近四季 EPS（證交所／櫃買每日公布）。
- **月營收**：近 24 個月營收、月增率、年增率、累計年增率（公開資訊觀測站）。
- **季財報**：近 8 季單季營收、毛利率、營益率、淨利率、EPS 與 EPS 年增（綜合損益表，累計數相減）。
- **標頭**：盤中會多一列即時現價與成交量（每 10 秒更新），下面一列是融資使用率、融資餘額與增減、融資佔股本、券資比。
- **融資融券**：融資使用率（＝融資餘額 ÷ 融資限額）、融資餘額／增減、融券餘額／增減、券資比（＝融券餘額 ÷ 融資餘額），附近 60 個交易日走勢圖。融資限額為 0 會顯示「停止融資」。融資在晚上約 9 點後才公布，18:45 那次會先顯示前一天並註明，21:45 那次補上。
- **籌碼分布**（兩張圓餅圖）：
  - 誰持有：外資及陸資持股、融資餘額、其他，皆佔發行股數（證交所 MI_QFIIS／櫃買僑外資持股，每天晚上更新）。
  - 持股規模：集保戶股權分散表（千張以上大戶、400～1,000 張、50～400 張、50 張以下），每週五晚上公布；開放資料只給最新一週，週數從開始抓的那週慢慢累積。
  - 下面另列外資持股比率 20 日變化、融資佔股本、外資／投信／自營近 20、60 日累計買賣超佔股本。投信、自營商沒有公布每檔持股，所以沒有畫進圓餅圖。
- **今日盤中**（盤中服務在跑時才有）：即時現價、5 分鐘成交額與外盤比、是否突破前 20 日高，以及今日分時圖（1 分鐘價格線＋成交量）。點進哪一檔就自動列為重點股、每 10 秒更新。
  - 分時只記錄盤中服務啟動之後的報價（證交所不提供當天較早的分鐘資料），開盤前就啟動才會有完整一天。
  - 盤中服務每分鐘把最後報價存到 `data\live\last.js`：服務關掉後到晚上官方資料出來前，個股頁仍顯示當天的收盤報價。
  - 收盤後才想看今天收盤價：雙擊 `live.bat`，它會把全部股票掃一輪（約 1 分鐘）並存檔。
- **回測這檔**：個股頁「短線動能」卡片下方的按鈕，會跳到「動能 → 回測」並只回測這一檔。
- 第一次更新會多抓不少資料（月營收與財報、本益比、2 年 K 線、外資持股），每天晚上的排程會分幾天補完。

## 板塊資金流（總覽、盤中分頁）

- **河道圖**：每個板塊一列，從中線往右＝流入（紅）、往左＝流出（綠）；河道越長金額越大、越粗成交越大，粒子沿河道流動。列會依金額自動重新排序；可選流入／流出各 8 名、各 15 名或全部，可勾「開根號刻度」讓小板塊也看得出長短。滑鼠移到列上看數字，點一下看成分股。上方三格：全市場合計、吸金最多、失血最多。
- **盤後・法人**：當日／近 5 日／近 20 日的法人淨流入（跟著右上角的法人口徑），回放＝近 30 個交易日一天一格。
- **盤中・主動買賣**：主動買賣淨額＝外盤成交額 − 內盤成交額（用報價快照估算），可看「開盤到現在」或「最近 N 分鐘」（間隔可選 3／5／10／15／30／60 分，或自訂，最短 3 分鐘；一般股票約每 1～2 分鐘才更新一次報價，間隔很短時數字會比較跳），回放＝從盤中服務啟動起每分鐘一格，每 30 秒自動更新。盤中服務每分鐘存檔到 `data\live\flow_last.js`（另留 `flow_日期.js`），服務關掉後也能回放當天。只從盤中服務啟動後開始累計，開盤前就啟動才有完整一天。盤中分頁最上方也有一張「即時資金流」。
  - 盤中模式點一下板塊：下方列出成分股在「同一個時段」（開盤到現在、最近 N 分鐘；回放時是那一分鐘）的主動買賣淨額、成交額、外盤比，依影響大小排序，點一列看個股。盤中服務沒開時，用存檔顯示每檔今天全天的累計。
- 想用舊的四象限泡泡圖：卡片上切到「四象限（舊）」。

## 每日總結（「每日總結」分頁）

看主力（法人＋千張大戶＋融資）最近往哪個板塊、哪些個股流動。可切換當日／近 5 日／近 20 日，右上角換日期可回看。

- **今日重點**：自動整理三大法人合計、資金最集中流入／流出的板塊、由賣轉買的板塊、籌碼集中個股、外資與投信買最多、千張大戶增加最多的板塊。
- **板塊資金流向**：當日／5 日／20 日淨流入、加速（5 日日均 − 20 日日均）、連續流入天數、5 日漲跌、千張大戶週變化、融資增減、狀態（加速流入、由賣轉買…）。點一列看板塊詳情。
- **主力動向個股**：「主力買進／主力賣出」切換。**籌碼集中**＝法人買超＋千張大戶增加＋融資減少（籌碼渙散相反），排在最前面。
- 千張大戶是集保每週資料（週五公布）；融資減少用紅色表示籌碼變乾淨。券商分點的主力進出資料要驗證碼才能查，沒有列入。

## 大盤（「大盤」分頁）

總覽、盤中分頁的加權／櫃買方塊，以及畫面最上方的「加權」「櫃買」字樣都可以點進來。

- **加權指數／櫃買指數**：日／週／月 K（5、20、60 日線）、成交金額、三大法人買賣超柱、大盤融資餘額、漲跌家數。
  - 三大法人金額：近 60 個交易日是官方金額，更早是個股買賣超 × 均價加總的估算（誤差約 1～3%，櫃買較大）。
  - 盤中服務開著時，標頭顯示即時指數與今日分時，K 線最後一根是盤中暫定的今天。
- **台指期**：近月連續日 K（可勾「含夜盤」）、外資淨未平倉、期現價差；三大法人未平倉（口數／金額）；大額交易人（前五大、前十大，特定法人或全部交易人）淨部位。
- 第一次執行會補抓最近約 2 年（每月一批，共約 175 個請求，多 15 分鐘左右）。
- **油價・匯率**：布蘭特原油（ICE 近月期貨，美元／桶）與美元兌台幣（1 美元換多少台幣，變大＝台幣貶值）的日／週／月 K，加上「走勢對照」（油價、匯率、加權指數以區間第一天為 0% 疊在一起看）。總覽上方也有兩個小方塊，點了會進來。
  - 資料來源 Yahoo Finance（`BZ=F`、`TWD=X`），抓不到時改用美國 FRED 的收盤價；每次 run.bat 更新，存在 `data\macro.js`。
  - **即時更新**：盤中服務開著時（08:40 排程或雙擊 live.bat）每分鐘抓一次最新價（含今日 5 分鐘走勢），總覽、盤中分頁的方塊與這一頁會跟著跳，K 線最後一根是今天的即時 K 棒。自己雙擊 live.bat 開的視窗，台股收盤後也會繼續更新油價與匯率，關掉視窗才停（排程開的收盤後保留 30 分鐘）。

## ETF（「ETF」分頁）

- **ETF 排行總表**：上市櫃所有 ETF 的收盤、漲跌（含配息調整）、5／20 日漲跌、成交金額、量比、三大法人（外資、投信、自營）當日與 5／20 日買賣超、規模、受益單位 20 日增減、融資增減。點欄位標題排序；可依類別、成交金額、代號或名稱篩選。
- **各類別 ETF**：市值型、高股息、主動式、台股主題、海外股票、債券、槓桿反向、商品期貨、平衡（依代號結尾與名稱自動分類，僅供參考）。
- **ETF 個股頁**（點任一檔）：K 線（含法人柱）、每日法人買賣超、外資／投信／自營分項、受益單位（增加＝申購、資金流入）、集保受益人數（每週）、近 20 日明細。畫面最上方的搜尋框也找得到 ETF（例如輸入 00878 或「高股息」）。
- 注意：ETF 的自營商（避險）多半是造市避險，雜訊大，可以在右上角法人口徑選「不含避險」。上市 ETF 的受益單位只有最近約 60 個交易日；集保受益人數從這版開始也收錄 00631L、00400A 這類 6 碼代號，之後每週累積。
- 第一次執行新版 run.bat 會用本機原始資料把約 2 年的每日資料重算一次（不連網，多 3～5 分鐘），之後就正常。
- **盤中即時**：盤中服務也會輪詢全部 ETF 的報價（約每分鐘一輪，正在看的那一檔每 10 秒），ETF 總表的價格、漲跌、5／20 日、盤中成交金額與量比（跟平常同一時間比）、個股頁標頭與 K 線最後一根都會即時更新；法人、規模、受益單位、融資仍是前一天盤後資料。

## 盤中即時（「盤中」分頁）

- 盤中服務（`live.py`）要在跑：直接雙擊 `dashboard.html` 或開 http://localhost:8765 都可以，網頁每 30 秒偵測一次服務，開了就自動連上。網頁本身不能直接連證交所，必須透過電腦上的盤中服務轉一手。
- 內容：大盤／櫃買指數、漲跌家數、大筆資金突破訊號、準突破、5 分鐘成交金額排行、自選股即時、板塊即時。
- **大筆資金突破**條件（可在盤中分頁按「調整條件」修改）：現價高於前 20 日最高價（已還原除權息）＋ 最近 5 分鐘成交金額 ≥ 0.5 億且是平常同時段的 3 倍以上 ＋ 預估全日量比 ≥ 1.5 ＋ 最近 5 分鐘外盤比 ≥ 60%。每檔每天只記第一次。
- 觸發後：盤中分頁置頂、動能分頁的選股清單會出現「盤中突破 時間」標籤；自選股觸發會進通知欄（鈴鐺）。
- **盤中即時動能**：「動能」分頁上方可切換「盤中即時／昨日收盤」。盤中版用現價當作今天收盤、量用預估全日量，每 60 秒重算一次分數與大盤燈號（全市場報價掃到 8 成後才開始算，開盤後約 1～3 分鐘）。盤中沒有法人資料，需要法人或板塊資金流向的策略盤中先隱藏；回測與門檻校準一律用收盤資料。
- 每天的訊號存在 `data\live\日期_events.json`。
- **視窗**：08:40 排程會開一個黑色視窗（標題 TWFlow live），開著就在更新；關掉那個視窗或執行 `stop_live.bat` 就會停止。在視窗裡點一下不會卡住；按 Ctrl+C 會整個停止（要複製文字請選取後按右鍵）。
- 同時只會有一個盤中服務：雙擊 `live.bat` 時如果已經有一個在跑，會請它結束、改由新開的視窗接手。
- 早上 08:40 啟動時若前一天的盤後資料還沒補抓，盤中服務會在補抓完成後 2 分鐘內自動改用最新資料。
- 公司電腦若禁止排程，就在開盤前手動雙擊 `live.bat`，並保持那個視窗開著。
- **限制**：資料來源是證交所「基本市況報導網站」，不是正式開放的 API，可能改版或暫時擋掉連線；報價本身常落後 30～90 秒（開盤前段最明顯），很多時候不給成交價，所以現價、5 分鐘金額、外盤比都是估算；三大法人盤中看不到，收盤後請看「動能 → 大筆資金突破」策略。
- 之後要改接券商或 Fugle 的即時 API：`config.json` 的 `live_provider` 是預留的切換點。

## 買進雷達與買進建議

- **買進雷達**（盤中分頁）：盤中服務即時偵測條件，一觸發就記一筆，只在清單裡看，不會跳通知。
  - 爆量突破＝突破前 15 分鐘高點且最近 3 分鐘量是平常同時段 3 倍以上；突破前 20 日高（量能、外盤都夠＝大筆資金突破）；急拉＝5 分鐘內拉 2.5% 以上；站上均價＝跌到今日均價下方後站回且外盤 ≥ 55%；委買強＝五檔委買遠大於委賣；觸及漲停／漲停再鎖／漲停打開（扣分）；爆量＝預估全日量 ≥ 5 日均量 3 倍。冷門股（20 日均成交 < 0.3 億）不偵測。
  - 分數＝盤中條件（最多 60）＋法人買超、站上 20 日線、動能達標、所屬板塊資金流入（各 10），70 分以上標紅。可依訊號種類、最低分數、只看自選股篩選。訊號每分鐘存到 `data\live\radar_last.js`，收盤後也看得到當天的。
- **買進建議**（個股頁右上）：盤中＝這檔今天的訊號＋均價線、外盤、五檔委買、預估量＋上面四個加分條件；盤後＝收盤突破前 20 日高、法人近 5 日買超、外資連買、量比、融資減少＋同樣的加分條件（下一個交易日參考）。70 分以上「買進建議」、50～69「可以觀察」、50 以下「暫不建議」，並列出參考進場價、短線停損（突破點或均價下方 1.5%）、波段停損（ATR(14) × 停損倍數）。
- 這是依條件自動算的參考，不是投資建議；盤中訊號沒有歷史分鐘資料可以回測。

## 板塊對照檔 sectors.csv

- 欄位：板塊名稱, 股票代號, 股票名稱（參考用）, 分類（產業／概念）
- 一檔股票可以出現在多列（屬於多個板塊）。分類欄可留空，留空視為「概念」。
- 用 Excel 編輯後，請「另存新檔 → CSV UTF-8（逗點分隔）」。改完執行 `run.bat` 或 `py fetch.py --rebuild`。
- 新上市而沒有寫進 CSV 的股票，會自動歸到「未分類」。

## 手機觀看

1. 在 `config.json` 的 `mobile_sync_dir` 填入雲端硬碟資料夾，例如：
   ```json
   "mobile_sync_dir": "C:/Users/你的帳號/OneDrive/twflow"
   ```
2. 每次執行後會在那裡產生 `twflow_dashboard.html`（資料已內含在檔案裡）。
3. 手機上用雲端硬碟 App 找到這個檔案，選「用瀏覽器開啟／在 Chrome（或 Safari）中開啟」。部分雲端 App 的內建預覽不會執行網頁程式，看到空白時請改用瀏覽器開啟。

自選股與設定存在各自的瀏覽器裡，電腦和手機不會互相同步。

## 自動排程沒有跑？

- 開「工作排程器」找 `TWFlow`（盤後）與 `TWFlow_Live`（盤中），確認狀態與上次執行結果；或看 `logs` 資料夾裡當天的紀錄。
- 公司電腦若禁止建立排程，就每天收盤後手動雙擊 `run.bat`。

## Mac 版

同一份程式也可以在 Mac 上獨立執行（Mac 自己抓資料、自己跑盤中服務、自己排程）。

1. 先裝 [python.org](https://www.python.org/downloads/macos/) 的 Python 3。
2. 打開「終端機」，輸入 `sh ` （後面有一個空格），把 `mac_install.sh` 拖進視窗，按 Enter。會安裝到 `~/twflow`（不放 OneDrive／桌面，避免兩台同時寫、避免 macOS 資料夾權限）。
3. 依提示：可選擇從 Windows 複製已抓好的 `data`、建立 launchd 排程（平日 18:45／21:45 盤後、08:40 盤中）、立即抓一次。再執行一次就是更新程式（`config.json`、`sectors.csv`、`data` 不覆蓋）。

| Windows | Mac |
|---|---|
| `run.bat` | `run.command` |
| `live.bat` | `live.command` |
| `stop_live.bat` | `stop_live.command` |
| `setup_task.bat` | `mac_install.sh`（launchd：`tw.twflow.fetch`、`tw.twflow.live`） |
| 工作管理員 | 活動監視器 |
|  | `開啟儀表板.command`、`移除排程.command` |

- Mac 的時區請設成台北（排程時間跟著 Mac 時區）。睡眠時錯過的排程喚醒後會補跑，關機錯過的不補。
- python.org 版 Python 的憑證：程式會自動匯出 Mac 系統根憑證到 `data/macos_roots.pem` 使用；還是連不上就執行「Install Certificates.command」。
- 建議用 Chrome；Safari 請用 `開啟儀表板.command` 或 `http://localhost:8765`。
- 詳細請看 `使用說明（Mac）.txt`。

## 下載與發佈新版本（Releases）

### 下載

到儲存庫右邊的 **Releases**，下載最新版：

- Windows：`twflow-windows-<版本>.zip`。第一次安裝：解壓縮後雙擊 `run.bat`、`setup_task.bat`。更新：關掉盤中服務後，把檔案全部複製到原本的資料夾、選「取代」。
- Mac：`twflow-mac-<版本>.zip`。解壓縮後在終端機 `sh ` ＋ 拖進 `mac_install.sh`（第一次安裝與更新都一樣）。

壓縮檔裡的設定檔叫 `config.default.json`、`sectors.default.csv`，不會蓋掉你改過的 `config.json`、`sectors.csv`；資料夾裡還沒有時，第一次執行會自動複製一份。

### 發佈新版本

1. 改好程式後，在 GitHub Desktop **Commit＋Push**。
2. GitHub 網頁 → **Actions** → 左邊 **Release** → **Run workflow** → 輸入版本（例如 `v2026.10.29`）→ **Run workflow**。
3. 約 1 分鐘後，Releases 會出現這個版本，附上 Windows 版、Mac 版兩個壓縮檔與安裝說明。

也可以推一個 `v` 開頭的 tag（GitHub Desktop：History 對 commit 按右鍵 → Create Tag → Push）自動觸發。同一個版本再跑一次會覆蓋壓縮檔。
打包程式在 `release/build_release.py`（本機也可以執行：`py release/build_release.py v2026.10.29`，輸出在 `dist/`）；流程設定在 `.github/workflows/release.yml`。
